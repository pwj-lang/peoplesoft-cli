# 发布规划

确定日期：2026-10-11。正式顺序为 **1.5.0 → 2.0.0**。**1.5.0** 已基于 rc.2 完成第二轮独立复验并形成正式包，GitHub 发行记录以仓库 Release 为准。

## 编号规则

正式 1.5.0 沿用仓库已有标签前缀，使用 `v.1.5.0`；之前的标签为 v.1.0.0、v.1.0.1。本地 2.0.0～2.4.2 是未公开的内部实施编号，保留历史记录。旧文档的 2.x 部署要求代表内部修复批次，1.5 包含这些修复和依赖。

日常代码、测试、文档编辑不升版。形成可部署验收包时递增 `1.5.0-dev.N`；范围完成后使用 `1.5.0-rc.N`，通过验收再发布 `1.5.0`。正式发布后的兼容修复用 `1.5.1` 等修订号，下一阶段使用 `2.0.0-dev.N`。新增对象本身不必改变接口契约；不兼容调整须说明迁移方式。规划、候选包和已发布状态分别记录。

## 1.5.0：五类初版与历史 BUG 收口

| 对象 | 范围与验收 |
|---|---|
| 服务 | 同步 REST Provider 读/新增/修改；PIA 定义与所属操作关联正确 |
| 服务操作 | 操作、版本、URI、消息绑定、Handler、Routing、指定列表授权及约定子定义删除；PIA 可搜索、配置可见，受控 REST 链路通过 |
| 菜单 | 标准/弹出菜单、栏/项目属性与排序、项目删除、ItemSelected 维护及真正删除；AD 与实际入口/弹出行为通过 |
| 消息目录 | 基准语言消息集/消息维护及精确单条删除；标准页面与多行/特殊字符回读通过 |
| 门户 | 已有 Portal 的 Folder/CREF/Link、导航、移动、排序、属性与显式权限；validate 与实际点击通过 |

统一要求为写前读取、写后独立回读、适用定义纳入确认的 Project、失败及部分成功可识别。回归 Action/Upgrade/Done 和 CopyProp 类型限制。SOAP、Consumer、异步、消息多语言、整份 Service/Menu/Portal 和门户文件夹删除沿用已确认的后置边界。

已有修复包括 Record 中间插入 Key、缓存/索引同步、Project 完整键与标记、PeopleCode/SQL 假成功、Serviceopr 关联、门户属性导航崩溃、固定 Project 键解析依赖。最终候选包应确认这些修复仍成立。

旧 PeopleCode 真正删除、Record 属性 AD 核验、弹出菜单运行验收、query-record 输入保护已于 2026-10-11 在 PANWX25 完成并关闭，详细事实见 [已知问题](known-code-issues.md)。1.5.0-dev.2 包完成同环境原生比较/回导入、健康检查和主要工作流复验；未做空白环境安装，也未创建正式发布或 Git 标签。1.5.0-dev.3 只整理维护工具（检查工具移出 skill、新增同步与打包脚本）并更新安装副本，服务端工程与数据契约未变，服务器证据沿用 dev.2。NCC 等业务专项不纳入工具缺陷。

发布条件：

1. 初版承诺验收通过，历史工具 BUG 实际修复并验证；不能用“暂不支持”代替关闭，无法完成的项明确调整范围和延期原因。
2. 在 PANWX25 / PeopleTools 8.60.10 核验对应 CLI、AD、PIA 行为，只声明已测试版本。
3. 最终服务端 Project 原生导出包含依赖和编译内容，日志/返回可查；在可恢复的验收环境完成导入、授权、健康检查及主要工作流。
4. 发行包、Skill、CLI、文档对应同一基线，更新限制和证据后形成正式包。

**1.5.0 延期项**：空白环境首次安装核验（当前无可用空白环境）延期至首次真实部署；替代证据为同环境原生比较/回导入、依赖与编译内容核验、授权与健康检查。首次部署若遇 180/74“找不到类”，按 Handler 与包依赖排查，不按授权失败处理。

## 2.0.0：三类新增与五类成熟版

| 新对象 | 目标 |
|---|---|
| Component Interface | 定义读取/新增/修改，覆盖核实后的属性、集合、方法和映射；AD 可验证并迁移，不把通过 CI 写业务数据等同于 CI 定义维护 |
| HTML | 定义属性与内容读取/新增/修改，文本、特殊字符、多行、AD 打开及 Project 迁移一致 |
| StyleSheet | 明确支持的样式定义类型，维护属性和内容；回读、AD 打开、受控页面效果及迁移通过 |

开发前按原生 API 核实操作与删除单位；不预设未经验证的能力。

五类初版的“成熟版”按功能矩阵验收：查找/列表/分页需求，属性与子对象范围，关联/权限完整性，清晰错误与分步失败恢复，新增/修改/删除及 Project 迁移回归。继续修复 1.5 后的缺陷，保持常用命令与数据契约兼容。

SOAP、Consumer、异步、消息多语言和整份定义/门户文件夹删除作为后续候选，进入 2.0 前逐项确定，不默认全部纳入。2.0 正式包须同时通过三类新增、五类成熟范围及 1.5 核心工作流回归。
